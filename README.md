# Mexican Fire

Marketing site for **Mexican Fire™** — dark chocolate with prickly pear, jalapeños, and chili powder. An exotic getaway of flavor, inspired by Cancún.

**Live site:** https://mexican-fire.pages.dev

**Taste the heat, crave the sweet.**

## Local

```bash
npm install
npm run dev
```

Then open the printed `localhost` URL (default port `8787`).

## Deploy

Static site on Cloudflare Pages:

```bash
npm run deploy
```

## Brand

- Product: dark chocolate, prickly pear, jalapeños, chili powder
- Line: *Exotic getaway of flavor*
- Line: *Taste the heat, crave the sweet*
- Place: Cancún / Mexican Caribbean
